# Zodiac Finder

A simple Python program that determines a user's zodiac sign based on their birth month and day.

## Features
- Supports all 12 zodiac signs  
- Takes user input for birth month and day  
- Uses conditional statements (`if`, `elif`, `else`)  
- Beginner-friendly Python project  

## How It Works
The program asks the user to enter their birth month and birth day.  
It then checks the input against zodiac date ranges and prints the correct zodiac sign.

## Requirements
- Python 3.x

## How to Run
1. Download or clone this repository  
2. Open a terminal in the project folder  
3. Run the program using:

```bash
python zodiac_finder.py
