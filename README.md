Zodiac Finder

A simple Python program that determines a user's zodiac sign based on their birth month and day.

Features
Supports all 12 zodiac signs
Takes user input for birth month and day
Uses conditional statements (if, elif, and else)
Beginner-friendly Python project
How It Works

The program asks the user to enter their birth month and birth day. It then checks the date against the zodiac date ranges and displays the corresponding zodiac sign.

Requirements
Python 3.x
Running the Program
Download or clone this repository.
Open a terminal in the project folder.
Run the program:
python zodiac_finder.py
Example
Zodiac Finder
Enter your birth month (January-December): July
Enter your birth day (1-31): 15

Your Zodiac sign is Cancer!
